Simulador de un Portal Escolar con una página para iniciar sesión y dashboards para administrador y usuarios con React Vite.

Inicializar el proyecto:
npm create vite@latest portal-escolar -- --template react

ESLint Yes

npm install Yes

En la carpeta /src borrar App.css y la carpeta /assets, sustituir los archivos base App.jsx y index.css por los que aparecen en este repositorio.

Dentro de /src agregar la carpetas /components, /data y /pages de este repositorio con sus archivos correspondientes.

Correr el servidor:
npm run dev
