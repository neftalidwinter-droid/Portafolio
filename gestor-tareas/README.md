Gestor de Tareas usando Angular

Inicializar el proyecto:
npm install -g @angular/cli@22

ng new gestor-tareas --style=css --routing --ssr=false

cd gestor-tareas

En /src reemplazar toda la carpeta /app por la de este repositorio.

Ejecutar con ng serve.

Terminar con: ng test --watch=false

y

ng build
