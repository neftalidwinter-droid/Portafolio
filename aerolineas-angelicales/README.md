Simulador de compra de boletos de una aerolínea que sale de Monterrey, N. L., con React Vite

Inicializar el proyecto:
npm create vite@latest aerolineas-angelicales -- --template react

ESLint Yes

npm install Yes

En la carpeta /src sustituir los archivos base App.jsx y App.css por los que aparecen en este repositorio.

Dentro de /src agregar las carpetas /components y /data de este repositorio con sus archivos integrados.

Correr el servidor:
npm run dev
