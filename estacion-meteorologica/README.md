Simulador de una Estación Meteorológica que devuelve la temperatura y la humedad en tiempo real en Montemorelos, N. L., con React Vite.

Inicializar el proyecto:
npm create vite@latest estacion-meteorologica -- --template react

ESLint Yes

npm install Yes

En la carpeta /public agregar la carpeta de este repositorio /img con las imagenes que contiene.

En la carpeta /src borrar App.css, sustituir los archivos base App.jsx y main.jsx por los que aparecen en este repositorio.

Dentro de /src agregar las carpetas /components, /data y /utils de este repositorio con sus archivos correspondientes.

Correr el servidor:
npm run dev
